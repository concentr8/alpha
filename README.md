# Concentr8 Alpha

Preview channel of Concentr8, the focus and study app for students.
Builds from this repository are rough and may break. The stable version
lives in the `concentr8` repository and on https://concentr8.github.io.

## Where things come from

- `server/`: the Concentr8 call server, imported unchanged (PR 1).
- `frontend/`, `backend/`, `docs/`, `AGENTS.md`: moved here unchanged from the
  Articul8 team repository (single commit, no history to carry over).

The frontend is published from `frontend/` by `.github/workflows/pages.yml`
at https://concentr8.github.io/alpha/.
